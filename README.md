# Малая теорема Ферма: визуальная лаборатория

Иллюстрированное объяснение малой теоремы Ферма через циклическую перестановку координат точек. После примеров в размерностях 2–5 статья связывает циклы с биномиальными коэффициентами и приводит доказательство по индукции.

[Открыть опубликованную статью](https://ivanbsp-coder.github.io/little-fermat-lab/). Для локального просмотра достаточно открыть [`index.html`](index.html) в браузере.

Редактируемые исходные схемы: [`assets/MTF_orbity_sloi_Pascal.drawio`](assets/MTF_orbity_sloi_Pascal.drawio).
